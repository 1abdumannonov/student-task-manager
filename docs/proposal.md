# Project Proposal

## Student Task & Schedule Manager

**Purpose:**
Provide students with a lightweight web application to manage subjects, tasks, deadlines, and weekly schedules. This project is built for academic evaluation focusing on clean architecture, testability, and clear design.

**Goals:**
- CRUD for subjects and tasks
- Deadlines and completion status
- Weekly schedule grouping (Monday-based)
- Internationalization (en, uz, ja)
- Local persistence using localStorage

**Deliverables:**
- Source code (vanilla JS)
- Documentation (design, workflow, tests)
- Minimal HTML/CSS for demonstration
