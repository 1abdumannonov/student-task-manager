# Student Task & Schedule Manager

A simple and user-friendly **Student Task & Schedule Manager** designed to help students organize their tasks, deadlines, and weekly schedules efficiently.

This project focuses on **clarity, simplicity, and usability**, making it easy for students to track their academic workload without complex setup.

---

## 🎯 Purpose

Many students struggle with managing multiple subjects, tasks, and deadlines.  
This project was created to provide a **lightweight, browser-based solution** that allows students to:

- Manage tasks by subject
- Track deadlines visually
- View tasks in a weekly schedule
- Avoid missing important assignments

---

## ✨ Features

- 📚 Subject management
- ✅ Task management (add / complete / delete)
- 🗓 Weekly schedule view (Mon–Sun)
- 📊 Dashboard overview:
  - Total subjects
  - Total tasks
  - Completed / pending tasks
- 🔄 Automatic schedule update based on task deadlines
- 🌍 Multi-language interface (English / Uzbek / Japanese)
- 💾 Persistent storage using `localStorage`
- 🎨 Clean and minimal UI design

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, Vanilla JavaScript
- **Storage:** Browser `localStorage`
- **No backend required**

## 🚀 How to Run

### Option 1: Open directly
Simply open `index.html` in any modern browser.

### Option 2: VS Code Live Server
1. Open the project in VS Code
2. Right-click `index.html`
3. Select **Open with Live Server**

---

## 📊 How It Works

- Tasks are assigned to subjects and deadlines
- The weekly schedule is **automatically generated** from task deadlines
- Completed tasks are visually dimmed
- Language preference is saved and restored automatically
